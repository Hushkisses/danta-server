# DEV-051 — Strategic resources

Status: IMPLEMENTED — awaiting Windows live/restart verification

## Source requirement
Execution plan v1.0 requires five strategic resources: food, wood, iron, rare mineral, mana stone.
Design v0.3 states strategic resources are national property and logically separate from ordinary Minecraft items.

## Implemented
- Fixed core enum: FOOD, WOOD, IRON, RARE_MINERAL, MANA_STONE.
- Nation-owned StrategicResourceStockpile with non-negative whole logical units.
- GameState remains authoritative in memory.
- Deposit/consume operations prevent negative stock.
- Snapshot schema v9 persists national strategic-resource stockpiles; v1-v8 remain readable.
- Resource mutations use existing async important snapshot flush path.
- Korean live verification output maps all internal resource IDs to 식량/목재/철/희귀광물/마력석.
- Admin commands:
  - /danta resource show <nation-id>
  - /danta resource set <nation-id> <food|wood|iron|rare_mineral|mana_stone> <amount>

## Scope boundary
- DEV-051 defines/storage-tests the five resources only.
- 30-minute runtime production belongs to DEV-052.
- Point production mapping belongs to DEV-053.
- Local isolated stockpiles belong to DEV-054.
- No Minecraft item conversion is added; v0.3 explicitly separates strategic resources logically from items.

## Windows verification
1. Stop Paper, pull main, run dev-server\\quick-deploy.bat.
2. Start dev-server\\start-dev.bat; confirm normal boot and DB status.
3. Run: danta resource show red
4. It must display exactly five Korean resource names.
5. Run:
   danta resource set red food 100
   danta resource set red wood 200
   danta resource set red iron 300
   danta resource set red rare_mineral 400
   danta resource set red mana_stone 500
6. Run show again and verify 100/200/300/400/500.
7. Stop and restart normally.
8. Run show again; all five values must survive restart.

Do not mark DEV-051 COMPLETE until live display and restart recovery pass.
