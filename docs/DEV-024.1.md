# DEV-024.1 — Player GUI Korean localization foundation

## Goal
Keep internal IDs/enums in stable English while showing Korean terminology to players.

## Implemented
- Added `UiText` as the shared player-facing localization boundary.
- Added Korean labels for `NationStatus`, `StrategicPointType`, and `BattlefieldTag`.
- Localized the existing `/국가` selector/detail GUI labels and status text.
- Internal nation IDs, point IDs, enum values, DB values, snapshots, and admin commands remain unchanged.
- Preserved the DEV-024 HOTFIX1 correction: `PointPosition.worldName()`.

## Rule going forward
Player-facing GUI/HUD text should use Korean labels through `UiText` (or a later data-driven localization layer). Raw enum names such as `ACTIVE`, `FARM`, and `ROAD` should not be shown directly to normal players.
