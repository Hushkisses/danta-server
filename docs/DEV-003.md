# DEV-003 — Paper 개발 서버 구성

상태: **구현 완료 / 실제 Java 25 서버 부팅은 개발 PC 수동 검증 필요**

## 목표

개발계획 v1.0의 DEV-003에 따라 DEV-001에서 고정한 Minecraft 26.2 / Paper 26.2 build 123 / Java 25 조합으로 재현 가능한 개발 서버 디렉터리를 구성한다.

## 구현

- `dev-server/setup-paper.bat` / `.ps1`
  - Java 25 확인
  - PaperMC 공식 Downloads Service 조회
  - 고정 build 123 및 STABLE 채널 검증
  - Paper 서버 JAR 다운로드
  - 공식 SHA-256이 있으면 무결성 검증
  - EULA는 자동 동의하지 않고 `eula=false` 생성
- `dev-server/start-dev.bat` / `.ps1`
  - server.jar / Java 25 / EULA 확인 후 실행
  - 메모리 기본값: Xms 2G / Xmx 4G
- `dev-server/server.properties`
  - 10인 개발 테스트를 위한 최소 설정
- 런타임 생성물은 Git에서 제외

## 자동 검증 결과

현재 실행 샌드박스에는 Java 25 및 외부 네트워크 실행 환경이 없어 Paper 서버 자체를 부팅할 수 없다. 대신 다음을 정적 검증했다.

- 필요한 스크립트/설정파일 존재
- 버전 문자열 26.2 / build 123 / Java 25 고정
- setup 스크립트가 임의 최신 버전으로 자동 변경하지 않음
- EULA 자동 승인 없음
- 서버 종료 시 사용자가 `stop`을 사용할 수 있는 정상 콘솔 실행 방식

## 수동 완료 테스트

1. Windows PC에서 `dev-server/setup-paper.bat` 실행
2. EULA 동의 시 `eula=true` 변경
3. `dev-server/start-dev.bat` 실행
4. Paper 콘솔에 서버 준비 완료(`Done`) 확인
5. 콘솔에 `stop` 입력
6. 오류 없이 종료되면 DEV-003 최종 DoD 통과
