# DEV-031.1 — Player-facing Korean output policy

Status: IMPLEMENTED — awaiting Windows build and Paper live-server verification

## Goal
Make Korean the default language for every player-visible command response, warning, rejection reason, status label, and GUI label while preserving stable English internal IDs and enum values.

## Implemented
- Translated legacy `/danta` command output for the development map, nations, strategic points, strategic edges, armies, snapshots, PostgreSQL, and server runtime.
- Added `UiText` mappings for army status, army order type/status, and database status.
- Reused the existing Korean mappings for nation status, strategic-point types, and battlefield tags.
- Converted known domain validation failures into Korean player messages.
- Kept detailed exception messages in the server console instead of exposing English implementation errors to players.
- Added focused tests for enum labels and ArmyOrder rejection translations.

## Language boundary
- Player-visible text defaults to Korean.
- Command names, internal IDs, enum input values, file paths, Java/Paper/PostgreSQL names, and UUIDs remain unchanged where they are technical identifiers.
- Internal logs retain diagnostic detail and may use English.
- New player-facing domain values must be translated through `UiText` before display.

## Windows live-verification checklist
1. Run the Gradle tests and quick deploy on the Windows development PC.
2. Start Paper and verify `/danta`, `/danta db status`, and `/danta runtime status` use Korean labels.
3. Verify `/danta nation show red`, `/danta point show red_capital`, and `/danta edge show e01` use Korean labels and translated enum values.
4. Create a test army and issue an adjacent movement order; verify the order type/status and army status are Korean.
5. Repeat the movement order and issue a non-adjacent order with another army; verify both rejection reasons are Korean and contain no raw English exception text.

Do not mark DEV-031.1 COMPLETE until the representative confirms these checks.
