# DEV-087 — Major-point-loss high-research deactivation

Status: IMPLEMENTED — Windows automated verification pending.

## Scope
- ResearchDefinition.requiredMajorPointType is the data-driven gate for completed high research that depends on ownership of a major/specialized point.
- Completed research remains learned permanently; ownership loss disables its effect rather than deleting completion.
- Regaining a matching owned point automatically makes the effect active again; no re-research is required.
- Research without requiredMajorPointType remains active after completion regardless of point ownership.
- Activation is derived from authoritative GameState strategic-point ownership, so no duplicate persisted active/inactive flag is introduced.
- Core tests cover active → point loss → inactive → recovery → active and ordinary research behavior.

## Deliberately deferred
- Final research content decides which research requires which point type; DEV-087 does not invent the tree.
- Exact effect application belongs to the later research-effect integration/content tickets.
- Player-facing GUI/status presentation is not expanded in this core ticket.
