# DEV-024 — /국가 최소 GUI

## 목표
명령어 텍스트 대신 인벤토리 GUI에서 국가 기본정보를 확인할 수 있게 한다.

## 구현
- `/국가` 명령(alias of `nationgui`) 추가.
- 국가가 1개면 해당 국가 상세 GUI를 즉시 연다.
- 국가가 여러 개면 국가 선택 GUI를 먼저 표시한다.
- `/국가 <nation-id>`로 특정 국가 상세 GUI를 바로 열 수 있다.
- 상세 GUI에 국가명/ID/상태, 국고, 수도, 보유 전략거점 수를 표시한다.
- GUI에서 아이템을 가져가거나 이동하지 못하도록 click/drag를 차단한다.
- 플레이어→국가 소속 데이터가 아직 없는 단계이므로 `/국가`의 다국가 상황에서는 임시 선택 GUI를 사용한다. 이후 국가 선택/소속 시스템이 생기면 자동으로 자국을 열도록 교체한다.

## 수동 테스트
1. 서버 재시작 후 인게임에서 `/국가` 실행.
2. red/blue가 모두 존재하면 선택 GUI가 떠야 한다.
3. Red Kingdom을 클릭하면 상세 GUI가 열려야 한다.
4. 국고/수도/보유 거점 수가 현재 GameState와 일치해야 한다.
5. GUI 아이템을 클릭/드래그해도 인벤토리로 가져올 수 없어야 한다.
6. `/국가 red`로 Red Kingdom 상세 GUI가 직접 열려야 한다.

## 완료 기준
- Paper에서 `/국가`가 정상 등록된다.
- 국가 선택 및 상세 GUI가 정상 작동한다.
- GUI가 게임 아이템 복사 경로를 만들지 않는다.
