# DEV-041 — CombatResolver v0

Status: COMPLETE — Windows build/test and Paper boot verification passed

## Goal
Create the first deterministic numeric combat resolver in core and make combat-simulator consume it.

## Formula
v0 follows the design formula:
troop count × troop-type coefficient × commander × research × terrain × supply × morale × counter.

DEV-041 accepts commander/research/terrain/supply/morale as explicit positive multipliers. Their authoritative gameplay systems are later tickets, so this resolver does not invent state or default bonuses for them. CombatSideInput.neutral supplies x1.0 placeholders for isolated simulation.

## Implemented
- CombatSideInput: side ID, basic troop type, troop count, and the five external multipliers.
- CombatResolver: deterministic effective-power calculation for both sides.
- DEV-040 soft counter is applied only when the attacking troop definition favors the opponent type.
- CombatSideResult exposes initial troops, base coefficient, applied counter, and effective power for later logs/UI.
- CombatResult reports winner or draw.
- combat-simulator now runs a 1000 infantry vs 1000 spearmen smoke case.
- Core tests cover equal neutral draw, +25% soft-counter application, and participation of all declared formula multipliers.

## Intentional scope boundary
- DEV-041 resolves effective power and winner only. Casualty/loss modeling is DEV-043.
- Fixed scenario suite belongs to DEV-042.
- Terrain mapping is DEV-044 and detailed battle logs are DEV-045.
- No Paper API or DB dependency is introduced into core combat.
