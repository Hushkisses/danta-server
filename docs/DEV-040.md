# DEV-040 — Basic troop types

Status: IMPLEMENTED — awaiting Windows build verification

## Goal
Introduce the four basic troop types required by Phase 4: infantry, spearmen, archers, and cavalry.

## Design basis
Design v0.3 fixes the basic roles and the soft-counter cycle as infantry -> spearmen -> cavalry -> archers -> infantry, with a strong matchup around +25%. The execution plan requires DEV-040 to provide data for those four types.

## Implemented
- Paper-independent core combat package.
- TroopType: INFANTRY, SPEARMEN, ARCHERS, CAVALRY.
- TroopRole: FRONTLINE, RANGED, MOBILE.
- TroopTypeDefinition with type, role, base-power coefficient, favored target, and favored-matchup multiplier.
- BasicTroopTypes registry encodes the v0.3 four-way soft-counter cycle at x1.25.
- Base power is deliberately neutral x1.0 for all four at DEV-040. The design fixes the formula concept but does not assign distinct basic coefficients; inventing balance values here would exceed the source.
- Unit tests verify all four definitions, roles, and the counter cycle.

## Scope boundary
- Magic troops and specialized troops are later content, not part of the DEV-040 execution-plan completion condition.
- Army composition persistence is not migrated in this ticket. DEV-030's baseTroops remains backward compatible until the combat tickets establish how compositions are consumed and persisted.
- DEV-041 will consume these definitions in CombatResolver v0.
