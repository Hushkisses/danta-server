# DEV-084 — ResearchState / Queue

Status: IMPLEMENTED — core automated verification passed; Snapshot v14/Paper/restart integration awaiting Windows verification.

## Scope
- Per-nation completed-research state.
- Default one active research slot, expandable to two as fixed by design v0.3; the later unlock condition is not invented here.
- FIFO reservation queue: queued research waits without consuming runtime until a slot becomes available.
- Active research uses the existing RuntimeScheduler and therefore server-running-time semantics.
- Completion/cancellation frees a slot and starts the next reservation.
- Restore contract preserves active task IDs/deadlines so later Snapshot integration can restore without advancing during downtime.
