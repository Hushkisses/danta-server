# DEV-072 — General troop synergy

Status: IMPLEMENTED — Windows automated verification pending

## Design basis
Design v0.3 states that generals can affect a specific troop type or the whole army, and that troop type / general combinations should be able to change combat outcomes. Earlier design examples include archer attack, infantry defense and cavalry performance effects. The finalized v0.3 general section does not assign fixed troop affinities or exact bonus percentages to grades/stats.

## Implemented
- GeneralTroopSynergy explicitly represents either:
  - ALL_TROOPS; or
  - one current basic TroopType.
- GeneralState can own, replace and clear an optional troop synergy.
- appliesTo(TroopType) provides a reusable match contract for later combat/equipment/trait integration.
- No percentage/multiplier field is introduced, so an unresolved balance value cannot accidentally become an implementation default.

## Important scope note
The current core TroopType enum contains the four DEV-040 combat types: infantry, spearmen, archers and cavalry. Design v0.3 also defines magic troops as a special-support family, but current DEV-040 intentionally did not include them in the basic combat enum. DEV-072 does not expand TroopType out of sequence merely to make a general synergy target.

## Explicit unresolved items
- which generals receive which troop-type/whole-army synergy;
- whether a general may have multiple simultaneous troop synergies;
- exact attack/defense/mobility/etc. effect attached to a synergy;
- exact numeric magnitude and grade/level/stat scaling;
- whether synergy comes from innate affinity, trait, unique ability, equipment, or multiple layers;
- magic-support/general synergy representation after that support system exists.

## Automated tests
Tests cover troop-specific matching, whole-army matching, optional GeneralState ownership and the absence of an invented numeric multiplier.
