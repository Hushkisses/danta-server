# DEV-085 — Four research fields / prerequisite eligibility

Status: IMPLEMENTED — Windows automated verification pending.

## Scope
- Preserve the four design fields as first-class ResearchField values: MILITARY, INDUSTRY, ADMINISTRATION, MAGIC.
- Research definitions can be queried by field without merging field identity into nation state.
- A research reservation is eligible only after every declared prerequisite research ID is completed.
- Queued/active research does not satisfy a prerequisite; completion is authoritative.
- Eligibility exposes explicit reasons for unknown/already-completed/already-queued/missing-prerequisite states.
- Missing prerequisite IDs can be reported separately for future Korean UI/Paper feedback.
