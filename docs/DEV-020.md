# DEV-020 — Nation domain

Status: implemented; requires Paper-side manual smoke test.

## Goal
Store nation ID, display name, capital strategic-point ID, treasury, and basic nation status in GameState and restart snapshots.

## Implemented
- `NationState` aggregate with validated ID/name, optional capital, non-negative treasury, ACTIVE/VASSAL status.
- `GameState` nation registry with duplicate-ID prevention.
- Snapshot schema upgraded from v1 to v2 to persist nations.
- Snapshot v1 remains readable and migrates to v2 with an empty nation list.
- DEV admin commands under `/danta nation` for create/list/show/capital/treasury/status.
- Nation mutations request an important asynchronous snapshot flush when PostgreSQL is READY.

## Smoke test

2. `/danta nation capital red capital_red`
3. `/danta nation treasury red 5000`
4. `/danta nation show red`
5. Restart the server.
6. `/danta nation show red` must still show capital_red and 5000G.
