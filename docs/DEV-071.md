# DEV-071 — General stats

Status: COMPLETE — Windows automated tests/build and Paper boot verified

## Design basis
Design v0.3 defines four general stat axes:
- command (통솔)
- martial (무력)
- intelligence (지력)
- politics (정치)

The available design/execution-plan material does not fix an authoritative stat range, per-grade base-stat table, per-level growth table, or exact mapping from each stat to combat/economy percentages.

## Implemented
- GeneralStats immutable value object with command/martial/intelligence/politics.
- GeneralState owns GeneralStats and exposes controlled replacement.
- Existing DEV-070 constructor remains source-compatible and initializes stats to zero.
- A stats-aware constructor is available for future creation/persistence integration.
- Stats must be non-negative.
- No arbitrary upper cap is imposed because the design does not define one.
- Level-up does not silently increase stats because no authoritative growth rule exists.
- CombatSideInput.commanderMultiplier remains unchanged; DEV-071 does not invent a stat-to-multiplier formula.

## Explicit unresolved balance items
- authoritative stat minimum/maximum range beyond non-negative domain validity;
- grade F-S base-stat generation/distribution;
- Lv1-10 stat growth per level;
- command -> army/combat effect coefficient;
- martial -> direct combat effect coefficient;
- intelligence -> tactics/research/combat effect coefficient;
- politics -> economy/administration effect coefficient;
- whether stat growth is fixed, random, selectable, or hybrid.

These are intentionally unresolved rather than silently treated as final values.

## Persistence boundary
General persistence is still not introduced by DEV-071. When generals become persistent player-owned season state, snapshot schema must be extended compatibly and old snapshots must remain readable.

## Automated tests
Tests cover all four stat axes, negative-value rejection, absence of an invented upper cap, GeneralState ownership/replacement, and no invented automatic stat growth on level-up.
