# DEV-002 — Gradle 멀티모듈 프로젝트 생성

## 목표
`core`, `paper-plugin`, `combat-simulator` 3개 모듈을 가진 Gradle 멀티모듈 프로젝트를 만들고,
`core`가 Paper API에 의존하지 않도록 경계를 고정한다.

## 구현 결과
- 루트 Gradle Kotlin DSL 구성
- Java toolchain/release 25 고정
- Paper repository 등록
- Paper API `26.2.build.123-stable` 고정
- `paper-plugin -> core` 의존성 구성
- `combat-simulator -> core` 의존성 구성
- 최소 Java 소스 및 core 단위테스트 추가

## 로컬 검증
현재 ChatGPT 실행 환경은 Java 21만 설치되어 있고 Gradle 및 외부 네트워크가 제공되지 않아
Paper dependency/Java 25 toolchain을 포함한 실제 Gradle build를 이 환경에서 실행할 수 없다.
대신 모듈 구조와 Java 소스 자체는 Java 21에서 문법 검증했다.

대표님 PC에서 Java 25 + Gradle을 준비한 뒤 다음 명령으로 최종 완료 검증한다.

```bash
gradle wrapper --gradle-version 9.7.1
./gradlew clean build
```

성공 기준: `BUILD SUCCESSFUL`, 세 모듈 build 디렉터리 생성, core 테스트 통과.
