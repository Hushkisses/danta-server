# DEV-054 — Local stockpile / supply isolation

Status: IMPLEMENTED — awaiting Windows live verification

## Source requirement
Design v0.3 section 10.4 distinguishes national total resources from resources available through the current supply network. Production in a region disconnected from the capital does not disappear; it remains as local stockpile and becomes available again when connectivity is restored. Detailed per-item logistics are intentionally avoided.

## Implemented
- SupplyConnectivityService determines a minimal own-territory path from a nation's capital through StrategicEdges.
- LocalResourceStockpile stores strategic resources at an isolated point.
- Production from a capital-connected owned point continues to national stockpile.
- Production from an isolated owned point goes to that point's local stockpile instead of disappearing.
- totalAmount includes national stock + all owned local stock.
- availableAmount includes national stock + local stock only at points currently connected to the capital.
- Reconnection makes retained local stock immediately available without simulating transport items.
- Snapshot schema v10 persists local stockpiles; v1-v9 remain readable.
- Korean diagnostics: /danta resource local-show <point-id>, /danta resource available <nation-id>.
