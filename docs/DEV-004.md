# DEV-004 — Plugin Bootstrap + `/danta`

Status: implementation/build-deploy automation complete; final acceptance requires one live Paper smoke test.

## Goal

Load the Danta Paper plugin and make `/danta` print development/build information.

## Implemented

- `kr.danta.paper.DantaPlugin` Paper bootstrap
- `plugin.yml`
- `/danta` command registration
- Startup/shutdown log messages
- Uses `DantaCore.version()` from the Paper-independent `core` module
- Fail-fast disable if `plugin.yml` command registration is missing
- Single deployable plugin JAR: `core` classes are bundled into `paper-plugin` JAR
- `dev-server/build-and-deploy.bat` / `.ps1`
- Build bootstrap pins Gradle 9.7.1 and uses Java 25
- Successful build automatically copies the JAR to `dev-server/plugins/`

## Expected `/danta` output

```text
[Danta Server DEV]
Plugin: 0.1.0-SNAPSHOT
Core: 0.1.0-SNAPSHOT
Minecraft/Paper target: 26.2 / build 123
Java target: 25
DEV-004 bootstrap is active.
```

Minecraft color codes are applied in game.

## Manual smoke test

1. Stop the development server if it is running.
2. Run `dev-server/build-and-deploy.bat`.
3. Confirm it ends with `Build and deploy complete.`
4. Run `dev-server/start-dev.bat`.
5. Confirm the console contains `Danta Server DEV enabled` and no fatal plugin error.
6. Join the server and run `/danta`.
7. Confirm the development information above is displayed.
8. Stop and restart the server once; confirm the plugin loads again.
