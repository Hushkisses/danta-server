# DEV-036 — Minimal army GUI

Status: IMPLEMENTED — awaiting Windows build and Paper client verification

## Goal
Provide the execution-plan minimum army GUI: army list plus location, status, troop count, and current movement/order information.

## Implemented
- New ArmyGuiController follows the existing NationGuiController/MapGuiController inventory-GUI pattern.
- /danta army gui opens a 54-slot read-only GUI for players.
- Each army shows owner nation, current strategic point, Korean status, base troop count, current order/status/route, and remaining sequential-operation route when present.
- STATIONED/MOVING/IN_BATTLE use shield/compass/iron-sword icons.
- Inventory clicks and drags are cancelled.
- Console use receives a Korean player-only explanation.
- No new DB I/O is performed from the GUI; it reads authoritative in-memory GameState and current operation-queue state.

## Scope boundary
This is the planned minimal DEV-036 GUI. Command issuance by GUI, pagination beyond the current 45 displayed slots, commander detail, troop composition, combat, and supply belong to later gameplay work.

## Windows live verification
1. Stop Paper, pull main, quick-deploy, and start the existing dev server.
2. Confirm /danta db status is 정상.
3. In the Minecraft client run /danta army gui.
4. A GUI titled 군단 현황 must open and list current armies.
5. Inspect a stationed army: owner, location, 상태=주둔 중, and base troop count must be visible in Korean.
6. Start a movement/queue on a fresh army, reopen /danta army gui, and verify 상태=이동 중 plus current 이동 command/route and remaining 연속 작전 route are shown.
7. After arrival, reopen the GUI and verify location/status refresh and completed order/queue information disappears.
8. Attempt to move GUI items by click/drag; items must not be removable.
9. Check server console for GUI exceptions.

Do not mark DEV-036 COMPLETE until representative client verification passes.
