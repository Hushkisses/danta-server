# DEV-MAP-004 전략지형 타일 설계

## 목적

DEV-MAP-003에서 확정한 평지 기반 전략 본토 `danta_main` 위에 강·산맥·숲·도로·평야 같은 전략 지형을 반복 가능한 모듈로 배치할 수 있는 기반을 만든다.

## 핵심 원칙

- 전략 본토는 자연 생성 지형을 게임 밸런스의 권위 데이터로 사용하지 않는다.
- 지형은 `TerrainTileSpec` 목록으로 정의하고 관리자 명령으로 명시적으로 생성한다.
- 타일 크기와 배치는 레이아웃 데이터가 결정하며, 이번 개발 샘플의 수치를 최종 시즌 맵 규격으로 간주하지 않는다.
- DEV-MAP-004는 기반과 개발용 샘플만 만든다. 최종 대륙 전체 지형과 미관 보정은 후속 작업이다.
- 기존 `ExplorerGuildBuilder`, `CanyonFortressBuilder`, 전략 거점 시스템을 삭제하거나 중복 구현하지 않는다.

## 타일 모델

`TerrainTileType`은 우선 다음 다섯 종류를 지원한다.

- `PLAINS`: 평야/기본 지면
- `FOREST`: 전략 숲
- `MOUNTAIN`: 전략 장벽용 산맥
- `RIVER`: 도하 지점을 통제할 수 있는 강
- `ROAD`: 이동축을 표현하는 도로

`TerrainTileSpec`은 격자 좌표 `(tileX, tileZ)`, 타입, 0~3의 90도 회전값을 가진다.

`TerrainLayout`은 `tileSize`, 타일 목록을 가지며 동일 격자 좌표 중복을 거부한다. 타일 크기는 레이아웃별로 바꿀 수 있어 최종 맵 스케일을 지금 확정하지 않는다.

## 렌더링

`StrategicTerrainBuilder`는 오직 `danta_main`을 대상으로 한다.

- 기준점은 전략 월드 스폰이다.
- 각 타일의 지면 높이는 스폰 바닥 높이를 기준으로 정규화한다.
- 생성 전 해당 타일의 개발용 상부 공간을 정리한다.
- `RIVER`와 `ROAD`는 회전값에 따라 남북/동서 방향을 바꾼다.
- `MOUNTAIN`은 실제 통행을 방해할 수 있는 높이의 능선을 만든다.
- `FOREST`는 결정론적 간격으로 나무를 배치한다.

이 생성기는 최종 아트 파이프라인이 아니라 프로토타입/배치 기반이다. 향후 검수된 타일을 NBT 또는 structure asset으로 치환할 수 있도록 논리 레이아웃과 월드 렌더링을 분리한다.

## 개발용 샘플 레이아웃

초기 검증용으로 작은 격자 샘플을 제공한다. 평야를 바탕으로 강 하나, 산맥 하나, 숲과 도로가 서로 다른 타일에 배치되어 방향과 경계가 눈에 보이게 한다.

샘플 타일 크기와 배치는 DEV 검증값이며 최종 밸런스가 아니다.

## 관리자 UX

- `/danta world terrain-status`: 샘플 레이아웃의 타일 크기/타일 수/종류를 출력한다.
- `/danta world build-terrain`: 전략 본토에 샘플 지형을 생성한다.
- 기존 `/danta world status`, `/danta world build-guild`는 유지한다.

플레이어에게 노출되는 메시지는 한글을 기본으로 한다.

## 검증

자동 테스트:
- 타일 회전값 범위 검증
- 중복 격자 좌표 거부
- 개발용 레이아웃에 다섯 기본 타입이 포함되는지 확인

Windows 실서버:
- quick-deploy 성공
- `terrain-status` 정상
- `build-terrain` 성공
- `danta_main`에서 강/산/숲/도로가 실제 생성됨
- 재시작 후 생성된 지형 유지
- `danta_wild`와 탐험가 길드 이동에는 영향 없음
