# DEV-021 — StrategicPoint domain

Status: implemented; Paper runtime test pending.

## Scope
- Strategic point ID / display name / type
- Optional owner nation ID
- Minecraft world anchor coordinates
- Base production-per-hour metadata
- Facility slot count
- In-memory GameState registration/lookups
- Snapshot schema v3 persistence and v1/v2 backward compatibility
- OP-only development commands for creation/inspection

## Notes
- Ownership mutation exists on the aggregate, but DEV-021 does **not** publish capture/ownership domain events. That is DEV-023.
- Production keys are strings until the formal economy ResourceType is introduced in DEV-051.
- No edge/connectivity logic is included; that is DEV-022.

## DEV commands
```
/danta point create <id> <type> <world> <x> <y> <z> <slots> <display name>
/danta point list
/danta point show <id>
/danta point owner <id> <nation-id|none>
/danta point production <id> <resource-key> <per-hour>
/danta point slots <id> <0-16>
```

Types: CAPITAL, FARM, FORESTRY, MINE, COMMERCIAL, ACADEMIC, BARRACKS, PORT, GATE, MAJOR
