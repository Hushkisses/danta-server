# DEV-030 — Army Domain

Status: COMPLETE — Windows build and Paper restart recovery verified 2026-09-15

## Goal
Represent an army with an owning nation, current strategic-point location, coarse lifecycle status, and base troop count.

## Implemented
- `ArmyState`: army ID, immutable owner nation ID, current strategic point ID, `ArmyStatus`, and non-negative base troop count.
- `ArmyStatus`: `STATIONED`, `MOVING`, `IN_BATTLE`.
- `GameState` army registry with duplicate-ID, owner-nation, and location-point validation.
- Snapshot schema v5 with army persistence and v1-v4 backward-compatible reads.
- Snapshot recovery restores armies after nations and strategic points.
- DEV admin commands:
  - `/danta army create <id> <nation-id> <point-id> <base-troops>`
  - `/danta army list`
  - `/danta army show <id>`
  - `/danta army troops <id> <base-troops>`
  - `/danta army status <id> <STATIONED|MOVING|IN_BATTLE>`
  - `/danta army location <id> <point-id>`
- Army mutations request an important asynchronous snapshot flush when PostgreSQL is READY.

## Scope boundary
DEV-030 stores one aggregate base-troop count. Four basic troop types and detailed composition remain DEV-040 work. Orders/routes and authoritative movement transitions remain DEV-031 through DEV-035.

## Automated checks added
`Dev030ArmyTest` covers:
- valid army registration and lookup
- duplicate army rejection
- missing owner nation and missing location rejection
- non-negative troop validation and state mutation
- schema v5 army round trip
- schema v4 decoding with an empty army list

## Windows live-verification checklist
1. Stop the Paper server.
2. Pull the latest `main` branch.
3. Run `dev-server\quick-deploy.bat` from the repository root.
4. Start the server with `dev-server\start-dev.bat`.
5. Confirm PostgreSQL reports READY with `/danta db status`.
6. Confirm nation `red` and points `capital_red`, `farm_a` exist. If the DEV map is not loaded, run `/danta devmap load`.
7. Run `/danta army create dev030_red_1 red capital_red 1200`.
8. Run `/danta army show dev030_red_1` and verify owner, location, `STATIONED`, and `1200`.
9. Run `/danta army troops dev030_red_1 950`.
10. Run `/danta army status dev030_red_1 MOVING`.
11. Run `/danta army location dev030_red_1 farm_a`.
12. Run `/danta army show dev030_red_1` and verify `farm_a`, `MOVING`, and `950`.
13. Stop the server normally and restart it.
14. Run `/danta army show dev030_red_1` again and verify the same values were restored.
