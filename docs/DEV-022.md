# DEV-022 — StrategicEdge

## Goal
Represent the strategic-point connection graph with base travel time and coarse battlefield traits.

## Implemented
- `StrategicEdge`: undirected connection between two strategic points.
- Endpoint validation and duplicate-pair prevention in `GameState`.
- Base travel time stored in milliseconds.
- Battlefield tags: `PLAIN`, `ROAD`, `MOUNTAIN_PASS`, `FOREST_PATH`, `CANYON`, `COASTAL`, `SEA_ROUTE`, `LANDING_ROUTE`.
- Adjacency lookup with `GameState.edgesForPoint`.
- Snapshot schema v4 with edge persistence and v1-v3 backward compatibility.
- Admin commands:
  - `/danta edge create <id> <point-a> <point-b> <travel-seconds> <tag[,tag...]|none>`
  - `/danta edge list`
  - `/danta edge show <id>`
  - `/danta edge travel <id> <seconds>`
  - `/danta edge tags <id> <tag[,tag...]|none>`
  - `/danta edge neighbors <point-id>`

## Validation
`Dev022CoreTest` compiles and passes:
- edge endpoint/adjacency behavior
- snapshot v4 encode/decode
- battlefield tag restoration

Result: `DEV-022 core test: PASS`

## Notes
Travel modifiers from roads, supply, terrain, generals, and research are intentionally not calculated here. DEV-022 stores the base graph data; DEV-032 will calculate effective movement time.
