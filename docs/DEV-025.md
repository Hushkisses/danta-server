# DEV-025 — `/지도` 최소 GUI

- 전략 거점 목록을 6행 인벤토리 GUI로 표시한다.
- 거점 유형, 소유국, 좌표, 시설 슬롯을 한국어로 표시한다.
- 각 거점 lore에서 인접 간선, 기본 이동시간, 전장특성을 확인할 수 있다.
- 하단 지도 정보 아이템에 전체 거점/간선 수를 표시한다.
- `/지도` (`mapgui` alias) 명령을 추가했다.
- GUI 아이템 이동/드래그를 차단한다.

현재 단계는 10거점 테스트맵 검증용 최소 GUI다. 실제 지형을 본뜬 슬롯 배치, 소유국별 시각 색상,
클릭 이동/상세 페이지 등은 후속 UI 티켓에서 확장한다.
