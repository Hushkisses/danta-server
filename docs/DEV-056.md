# DEV-056 — Expedition supply selection

Status: IMPLEMENTED — awaiting Windows automated + Paper verification

## Goal
Allow a stationed army to choose an expedition supply level before military action.

## Implemented
- LIGHT / STANDARD / HEAVY levels with Korean player-facing names 경량 / 표준 / 대량.
- Provisional balance amounts: 100 / 300 / 600 FOOD.
- /danta army supply <army-id> <LIGHT|STANDARD|HEAVY>
- Loading deducts FOOD from the owning nation's strategic stockpile and stores the selected level + carried FOOD on ArmyState.
- Insufficient FOOD rejects the load without partial deduction.
- Supply can only be loaded while STATIONED.
- Army show output displays supply level and carried FOOD.
- Snapshot schema v11 persists both fields; decoder keeps compatibility with older 5-field army rows and schemas v1-v10.

## Balance note
The design fixes the three selectable levels but not their exact numeric amounts. 100/300/600 are deliberately provisional and must remain easy to rebalance.

## Scope boundary
Actual consumption from carried FOOD and shortage effects during expedition are later supply/combat work. DEV-056 establishes selection, loading, deduction, display and persistence.

## Verification
Run quick-deploy; all automated tests must pass. Then on Paper set known red FOOD, load each tier on a stationed test army, verify deduction/display, reject insufficient FOOD, restart and verify selected level/carried FOOD persist.
